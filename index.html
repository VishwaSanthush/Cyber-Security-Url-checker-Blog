🛡 AI Cyber Shield URL Checker

AI-Powered Chrome Extension for detecting malicious and suspicious websites in real time using Machine Learning and Cybersecurity technologies.

About The System

AI Cyber Shield URL Checker is a smart cybersecurity browser extension developed using Python, FastAPI, Machine Learning, and Chrome Extension technologies.

The system captures the active website URL from the browser and analyzes it using an AI model trained with malicious and safe website datasets.

The extension instantly predicts whether the website is safe or malicious and displays the result in a professional popup interface.

How The System Works

1

User opens a website in the browser.

2

The extension captures the active URL.

3

The URL is sent securely to the FastAPI backend.

4

The AI model predicts whether the website is safe or malicious.
